# MCP Server: Free Web Search & Page Reader (DuckDuckGo)

[![MCP](https://img.shields.io/badge/MCP-Server-blue)](https://modelcontextprotocol.io)
[![Python](https://img.shields.io/badge/Python-3.10+-brightgreen)](https://python.org)

A fast, async Model Context Protocol (MCP) server providing web search, news retrieval, content privacy redaction, and full Markdown page fetching without requiring third-party API keys.
